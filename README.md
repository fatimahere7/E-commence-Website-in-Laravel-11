# E-Commerce Website in Laravel 11

A full-stack **E-Commerce Website** developed using **Laravel 11**, following the MVC architecture. The project provides a complete online shopping experience with product management, user authentication, shopping cart functionality, and order management.

## 🚀 Features

* 🔐 User registration and authentication
* 🛍️ Product browsing and product details
* 🛒 Shopping cart functionality
* 📦 Order management
* 👤 User profile management
* 🗂️ Product and category management
* ✏️ Create, read, update, and delete (CRUD) operations
* 🔎 Product search and filtering
* 📱 Responsive user interface
* 🗄️ Database-driven application using Eloquent ORM

## 🛠️ Tech Stack

* **Laravel 11**
* **PHP**
* **MySQL**
* **Blade**
* **Eloquent ORM**
* **HTML5**
* **CSS3**
* **JavaScript**
* **Bootstrap**

## 🏗️ Architecture

The application follows the **MVC (Model-View-Controller)** architecture provided by Laravel.

```text
User
 ↓
Routes
 ↓
Controllers
 ↓
Models / Eloquent ORM
 ↓
MySQL Database
 ↓
Blade Views
 ↓
User Interface
```

## 📋 Core Functionality

### User Management

Users can register, log in, and manage their account.

### Product Management

Products and categories can be managed through CRUD operations, including creating, updating, viewing, and deleting products.

### Shopping Cart

Users can add products to their cart, update quantities, remove items, and review their cart before placing an order.

### Order Management

The application handles the process of creating and managing customer orders.

## 🎯 Project Goal

The goal of this project was to build a complete e-commerce application while gaining practical experience with **Laravel 11, MVC architecture, Eloquent ORM, database relationships, CRUD operations, authentication, and backend development**.
